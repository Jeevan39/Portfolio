# Portfolio Website

A modern, responsive developer portfolio website built using HTML5, CSS3, and JavaScript. The website showcases my profile, technical skills, education, projects, achievements, and contact information.

## 🚀 About the Project

This portfolio is designed to present my technical background, development projects, and professional experience through a clean, interactive, and user-friendly interface.

The website features a modern dark theme with blue and violet accents, contemporary typography, animated elements, and responsive layouts for desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content
- **CSS3** — Styling, responsive layouts, animations, and visual effects
- **JavaScript** — Interactive elements and dynamic user interface
- **Font Awesome** — Icons
- **Google Fonts** — Typography

## 💻 How to Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure the `css`, `js`, and `assets` folders are in their correct locations.
4. Open `index.html` in your browser.

For a better development experience, install the **Live Server** extension in Visual Studio Code, then right-click `index.html` and select **Open with Live Server**.

No backend or database is required to run this static frontend version.

## 🌐 Deployment

This website can be deployed using Netlify or GitHub Pages.

### Deploy Using Netlify

1. Push the project to GitHub.
2. Sign in to [Netlify](https://www.netlify.com/).
3. Import your GitHub repository.
4. Set the project root directory as the publish directory.
5. Leave the build command empty because this is a static website.
6. Deploy the website.

### Deploy Using GitHub Pages

1. Open your repository on GitHub.
2. Navigate to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and the root folder.
5. Save the settings and wait for deployment.
